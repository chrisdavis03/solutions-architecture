# Notes

Study notes, certification prep, and learning scratchpads. Anything you write down while figuring something out lives here: service limits, exam objectives, command cheat sheets, half-formed comparisons.

These are raw. They do not need the post frontmatter (title, date, status, tags) and they do not need an audience. Write for yourself, name files however you will find them again.

When a note firms up into something reusable, move the durable part to `patterns/` or `posts/`. Do not polish notes in place — a note that stays messy is still doing its job.
